VeriMark Privacy Policy

Last updated: September 29, 2026

VeriMark is a fully offline Android application for reviewing local videos, marking incident timestamps with labels, and exporting PDF reports. This policy explains what information the app handles and how it is stored.

1. Data we collect

VeriMark does not collect, transmit, or share any personal information. The app does not include analytics, advertising, crash-reporting, or any other third-party SDK, and it does not request the INTERNET permission.

2. Data stored on your device

All data you create is stored locally on your device and never leaves it:

  • Project names and creation dates.
  • Video file references (content URIs you select via the system file picker).
  • Incident markers: timestamps, labels, and creation times.
  • Exported PDF and JSON files, written to the app's private cache directory or to a location you choose.

This data is held in a local Room database and in the app's private storage. No data is backed up to, or synchronized with, any server.

3. Permissions

VeriMark uses the Android Storage Access Framework to let you choose which videos to open. When you select a video, the app requests a persistable read permission for that specific file so access survives app restarts. The app does not request broad storage access and does not read any file you have not explicitly selected.

4. Data retention and deletion

Data remains on your device until you delete it. You can delete individual markers, clear all markers for a project, or delete an entire project (including its markers) at any time from within the app. Uninstalling the app removes all locally stored data.

5. Third parties

VeriMark has no server backend and does not engage any third-party data processors. Because the app is entirely offline, no data is ever shared with us or with anyone else.

6. Children’s privacy

VeriMark is a professional tool intended for investigators and claims professionals. It is not directed at children, and it does not knowingly collect information from anyone.

7. Changes to this policy

If this policy changes, the updated version will be published at this location with a new “Last updated” date.

8. Contact

If you have questions about this privacy policy, please contact the app maintainer through the project’s GitHub repository.
